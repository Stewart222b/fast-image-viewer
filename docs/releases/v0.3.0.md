# 🖼️ Fast Image Viewer v0.3.0

新增 WebP 支持，改善连续切图体验，并补充常用的图片和文件操作。

## ✨ 新增功能

- Windows 内置 WebP 解码器，支持有损、无损、透明度与 EXIF 方向，无需额外安装编解码器。
- Windows 提供浅色与深色主题，可通过工具栏、菜单或 `D` 切换，并记住上次选择。
- `Ctrl+C` 复制当前方向的图片，保留透明度；`Ctrl+V` 粘贴图片、图片文件或文件路径。
- `Ctrl+Enter` 定位原文件：Windows 和 macOS 选中文件，Linux 打开所在目录。
- `K` 切换切图时保持缩放与位置，便于连续查看局部细节。
- 新增 Linux 和 macOS 版本的源码与构建脚本。

## ⚡ 体验改进

- 预加载相邻图片，并缓存已解码的图片，减少重复加载。
- 快速切图时优先处理最新请求，取消过时的排队任务。
- 状态栏明确显示平滑或像素模式，菜单勾选当前选项。
- 保留以鼠标位置为中心的连续滚轮缩放和紧凑界面。

## 💻 下载与运行

- 本次准备的二进制包为 `FastImageViewer-v0.3.0-win-x64.zip`。
- Windows 10 / 11 x64，需要 .NET Framework 4.8。
- 解压完整 ZIP 后运行 `FastImageViewer.exe`，无需安装；请保留配置文件与第三方许可文件。
- Linux / macOS 可按 README 从源码构建；macOS 构建未签名。

## 📌 已知限制

- GIF、动画 WebP、TIFF 等多帧格式只显示第一帧。
- 暂不支持 AVIF、HEIC、RAW 和 SVG。
- 超过 32 MP 的图片采用缩小预览，复制时也使用预览像素。
- Windows WebP 暂不进行 ICC 色彩转换。
- 新增跨平台桌面操作仍需实际系统上的人工试用反馈。
